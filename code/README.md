# The programs

| Path                              | What it does                                                                                                                                                                                                                                 |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `soq/`                            | Rust, `soq`: computes the tables of the certificate of Section 5 of the paper, values and slopes, backward in time, in exact integer arithmetic (`i128`, overflow checked); option `emitall=DIR` writes the grid file and one table per time |
| `soq/run.sh`                      | `soq` on the run of the paper (`n = 300`, `m = 5`, `rho = 1.3`, window `[0.35, 14]`), its output without the times                                                                                                                           |
| `soq/out/`                        | the recorded output of `run.sh` and the grid file (`n m SH K J`, the integers `P_j`, the window starts `j_t`), and `tables.sha256`, the sha256 of the grid file and of the 300 tables of the run of the paper                                |
| `so-pack/`                        | Rust, `robbins-so-pack`: writes the grid and one table as Lean modules (a table is a list of literals of 16 states, each value and slope in 48 bits)                                                                                         |
| `formal-proof/gen.sh`             | writes the data modules under `RobbinsSO/N300/`: the grid, the 300 tables, the 4837 theorems `decide +kernel` (each on a range of states of one time, or on a window of the packed states of one top record), the chain and the final bound  |
| `formal-proof/modules.sha256`     | the sha256 of every file `gen.sh` writes                                                                                                                                                                                                     |
| `formal-proof/clean_build.sh`     | the build of the package in dependency order, the step modules four at a time (each peaks near 2.5 GB), the heavy modules one at a time                                                                                                      |
| `formal-proof/main_axioms.lean`   | `#print axioms` of the theorems of `config.json`                                                                                                                                                                                             |
| `formal-proof/facts.lean`         | the number of hypotheses and axioms of the theorems of `config.json`, for the badges                                                                                                                                                         |
| `gp/numbers.gp`, `gp/numbers.out` | PARI/GP: the numbers of the paper that follow from the grid file and the output of `soq` (`J`, the 280 times with `G_{t+1} = G_t`, `binomial(20, 5)`, the value at time 1 and its decimals)                                                  |

Both Rust programs build with the toolchain of their `rust-toolchain.toml`, Rust 1.98.1. The tables of the paper were computed with Rust 1.101 (nightly of 2026-10-01); with 1.98.1, `soq` writes the same grid file and the same 300 tables, byte for byte, as `code/soq/out/tables.sha256` records and the job data of CI checks. The tables are about 340 MB and the data modules about 330 MB; neither is committed. The proof trusts neither program: the Lean kernel checks the tables, and the theorem of `Robbins/Cert/SO/RunMain.lean` turns the checked chain into the relaxed sub-solution of Proposition 2.4.
